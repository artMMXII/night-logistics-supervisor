ОБНОВЛЕНИЕ «НОЧНАЯ ЛОГИСТИКА» — МОДУЛЬ РАСПРЕДЕЛЕНИЯ СМЕНЫ

В архиве:
- index.html — существующая главная страница с добавленной ссылкой на новый модуль;
- distribution.html, distribution.css, distribution.js — новый модуль;
- sw.js — обновлённый Service Worker для офлайн-кэширования нового модуля.

КАК УСТАНОВИТЬ
1. Скачайте архив и распакуйте его.
2. В репозитории GitHub night-logistics загрузите index.html и sw.js с заменой существующих файлов.
3. Добавьте distribution.html, distribution.css и distribution.js в корень репозитория.
4. Не заменяйте app.js, styles.css, manifest.webmanifest и icon.svg — они остаются прежними.
5. Откройте GitHub Pages. На главной странице появится ссылка «Распределение смены».

ДАННЫЕ
- Остатки паллет и распределение сотрудников хранятся раздельно в localStorage.
- Модуль распределения читает остатки из существующей ведомости только для сортировки подсказок по помощи.
- Изменения сохраняются на текущем устройстве и не синхронизируются между разными телефонами/компьютерами.
